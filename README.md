# Machine Learning Repository

This repository contains the labs and final project for the machine learning coursework.

## Structure

- `lab01/` to `lab11/`: individual lab directories with reports, source code, and result artifacts
- `project/`: final project with source code, outputs, and documentation
- `data_card.md`: dataset documentation
- `model_card.md`: model documentation

## Setup

```bash
pip install -r requirements.txt
```

Each lab directory contains:
- `report.md`: summary and analysis
- `src/`: implementation code
- `results/`: generated outputs and plots
